# The K4510 User's and Programmer's Guide

**A fantasy 8/16-bit computer** — CPU 45GS10 · VICKY · MELODY · 256 MB RAM

The K4510 is a machine that never existed, built the way 1985 might have
built it with no budget committee in the room: its own CPU, video chip,
sound and operating system, with seven languages one word away. It runs
as a whole computer from a USB stick, installed beside another system, or
in a window on a Linux desktop.

This site is the handbook, page for page. The same book is also a
[PDF](https://github.com/mlongval/k4510/raw/master/doc/guide/k4510-guide.pdf),
made from the same source at the same time, and the machine itself is on
[GitHub](https://github.com/mlongval/k4510).

!!! note "This is alpha documentation"
    It describes a machine that is still being built, and it is written
    alongside it. Everything in it — commands, keys, registers, the layout
    of files, the names of things — is subject to change. Where the book
    and the machine disagree, the machine is right and the book is behind
    it; [Filing an Issue](a2-issues.md) says how to tell us.
